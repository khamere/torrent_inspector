Three steps for everyday use

Setup is saved. You do not need to open another settings panel for each torrent.

1 · Connect once

Open Set up trackers, then choose Connect Prowlarr or Add a tracker manually. Your keys and tracker choices are remembered.

2 · Check this torrent

Read the findings and matching releases in the same box. Use Retry for a failed tracker or Search more broadly when the search is too narrow.

3 · Copy and finish

Use Copy MediaInfo or Copy description beside the release you need. Descriptions keep their original BBCode. Complete the manual checks and press Mark reviewed.

Everything stays in the box

A short scrolling area keeps long result lists from stretching the tracker page.

Check and review buttons stay accessible. Wider screens show results in columns; phones stack them. As scans arrive, your reading position, open details and focus are kept. Each result shows its title and any reported filename before you open Details.

For a queue, choose Review loaded titles on a listing, then open a torrent. Mark reviewed & next continues when another queued item is available. In Advanced review, Next unchecked follows the captured queue. Listing settings remain under Settings & tools.

See what actually matches

A release name is a starting point. The returned evidence tells you what can be compared.

Reports, hashes and bytes

Details compares MediaInfo IDs, filenames, exact file bytes and available v1 torrent hashes. Missing fields stay unknown. A name/size match does not confirm identical media or HDR.

Oldest returned matches first

Uploads are ordered oldest first within each comparison group, with missing dates last. This ranks returned results; it does not prove where a release originated.

Scene and home trackers

A listed home gives a recommended tracker search. Scene-listed and unlisted groups can use Search srrDB by title and group. It opens only when clicked and does not automatically confirm a scene record.

A matching report for one episode does not prove that an entire season pack is identical. Advanced mode keeps remembered-page comparisons in Source check and episode tables in Season check. Last saved check on another page is older stored evidence, shown separately.

Use the trackers you already have

Prowlarr

Enter the server address and API key, then press Connect once. Supported direct keys are imported. Configured trackers such as TorrentLeech and FileList use search fallback automatically, without a second checklist.

Direct tracker keys

Choose Add a tracker manually, select the tracker and press Save & test. PeerGarden supports direct searches, MediaInfo, original BBCode and available torrent hashes.

Your saved setup

Updating the normal installation preserves its keys and settings. Blank saved-key fields are intentional. Keys are excluded from backups; no credentials are shipped in the project.

Fallback results may have no MediaInfo or original description to copy. The script does not invent missing reports.

More detail when you need it

Press Advanced mode at the top of the box. Return to Easy mode without losing your results.

Advanced tools also include private notes, naming templates, captured-release comparisons and rules profiles. The Rules builder helps you create a profile for your tracker.

Install or update

The script is handed out privately to moderators and staff of supported trackers. Ask DKOKTO on your tracker for the installation address. This public website carries the screenshots and Rules builder; it does not offer the userscript for download.

  1. Install Tampermonkey, then open the supplied installation link.
  2. Update the existing Torrent Inspector entry and reload your tracker tabs.

Your saved keys and settings are retained when you update.

A few useful answers

Does green mean the upload is approved?
No. It means the supported checks passed. The tool reads posted evidence, not the actual media, and never approves a torrent.
Do I need to open every tracker?
Connected APIs can return evidence into the same box. Unsupported APIs and missing content may still need an explicit website visit.
Where are my keys?
In your installed script's browser storage. They are reused for later checks and excluded from backups. Prowlarr cookies, passwords and RSS passkeys are not copied.
Can I keep using the original interface?
Yes. Use Advanced mode. Findings, MediaInfo, Find releases, Source check, Season check and notes remain available.
What does it send?
The API searches you request, using each destination's own key. It sends no usage telemetry and never submits tracker changes. External lookup links open only when clicked.
