Three steps for everyday use

Setup is saved. You do not need to open another settings panel for each torrent.

1 · Open a torrent

Read the verdict line. Open Automatic checks for the page evidence and Needs you for manual checks. No API key is needed for the loaded-page checks.

2 · Connect once

Set up trackers shows Prowlarr import and a manual tracker-key form together. Use either path and save/test a connection. Check this torrent searches connected trackers; your setup is remembered.

3 · Copy and review

Use the copy buttons on a result for its report or original BBCode. Details opens its comparison and report. Use Retry beside a failed tracker. Finish the manual checks, then use Mark reviewed to save your progress.

See what actually matches

A release name is a starting point. The returned evidence tells you what can be compared.

Reports, hashes and bytes

Details compares MediaInfo IDs, filenames, exact file bytes and available torrent hashes. Full Blu-ray BDInfo can show Matching disc report when the disc label, disc bytes, playlist and tracks agree. Check a local .torrent file compares chosen v1/v2/hybrid metadata locally. Matching names and sizes alone do not confirm identical media. Missing or shortened reports stay for review; these checks do not verify actual media.

Oldest returned matches first

Uploads are ordered oldest first within each comparison group, with missing dates last. This ranks returned results; it does not prove where a release originated.

Scene and home trackers

A listed home gives a recommended tracker search. Scene-listed and unlisted groups can use Search srrDB by title and group. It opens only when clicked and does not automatically confirm a scene record.

A matching report for one episode does not prove that an entire season pack is identical. Local Season-pack checks run when the file list appears, before the main check, with a visible Missing episode numbers warning for interior gaps. Expand the section for filenames, sizes and comparisons. Expected episodes (optional) accepts your count or list for this torrent and visit; it takes precedence for partial packs and can check leading or trailing absences. Incomplete or ambiguous lists stay unconfirmed. No official season length is guessed, no extra API call is made and the tracker’s title is not changed. The review tools keep the original Season check tab. Last saved check on another page is older stored evidence, shown separately.

Use the trackers you already have

Prowlarr

Enter the base server address (including its application prefix, without a settings-page path) and API key, then press Connect once. If your seedbox asks for a separate login, fill Server login (optional) first, using an HTTPS address. Supported direct keys are imported. Configured trackers such as TorrentLeech and FileList use search fallback automatically, without a second checklist.

Direct tracker keys

In Manual · One tracker key, select the tracker, paste its API key and press Save & test. PeerGarden supports direct searches, MediaInfo, original BBCode and available torrent hashes.

Your saved setup

Test all connections checks saved supported direct keys and Prowlarr discovery without changing selections. Updates retain settings and keys already saved in Tampermonkey; older page-only credentials need one-time re-entry. Blank key fields are intentional. Keys stay private and excluded from backups.

Use Copy MediaInfo or Copy BDInfo for the original report, and Copy description for its original BBCode. Fallback results may have no report or original description to copy. The script does not invent missing reports.

More detail when you need it

Expand a check or open the detailed review tools for reports, comparisons and private notes.

Install or update

The script is handed out privately to moderators and staff of supported trackers. Ask DKOKTO on your tracker for the installation address. This public website carries the screenshots and Rules builder; it does not offer the userscript for download.

  1. Install Tampermonkey, then open the supplied installation link.
  2. Choose Install for first use or Update for your existing Torrent Inspector entry, then reload your tracker tabs.

Settings and keys already saved in Tampermonkey are retained. Older page-only credentials need one-time re-entry.

A few useful answers

Does green mean the upload is approved?
No. It means the supported checks passed. The tool reads posted evidence, not the actual media, and never approves a torrent.
Do I need to open every tracker?
Connected APIs can return evidence into the same box. Unsupported APIs and missing content may still need an explicit website visit.
Where are my keys?
In Tampermonkey's private script storage. They are reused for later checks and excluded from backups. Optional server logins use the same private storage and go only to your saved Prowlarr server. Prowlarr cookies, passwords and RSS passkeys are not copied.
Where are the detailed tools?
Review keeps Findings, MediaInfo, Find releases, Source check, Season check and notes as stacked expandable sections. The torrent-page drawer also offers In page placement.
What does it send?
The API searches you request, using each destination's own key. Screenshot checks read loaded counts and dimensions. It sends no usage telemetry and never submits tracker changes. External lookup links open only when clicked.
Does the local torrent check contact a tracker?
No. Choose a .torrent file up to 16 MiB and 10,000 files. Its metadata is read in this tab, never uploaded, announced or saved in settings. Hashes and byte counts cannot verify actual media files.
What do screenshot checks compare?
The number of description images and their loaded sizes against the posted video. Unloaded sizes stay unknown. Open Automatic checks, then Screenshots for details. Original-image and viewer links open only when clicked.
