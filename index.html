Every loaded title, checked as the page renders

Open a listing, a member's uploads, bookmarks, a moderation queue or a film's own page. Every release name gets a badge. Hover for the reason, click for the whole judgement.

✓ The Money Pit 1986 1080p BluRay DTS 5.1 x264-iJiA

The supported title checks passed — not that the media, the source history or tracker approval were verified.

✕ Dead.Silence.2007.2160p.UHD.BluRay.DTS-HD.MA.5.1.DV.HDR.x265-B0MBARDiERS

The guide writes display titles with spaces. Corrected for you: Dead Silence 2007 2160p UHD BluRay DTS-HD MA 5.1 DV HDR x265-B0MBARDiERS — the dots that belong (H.264, DDP5.1) are kept.

Something needs your judgement — an uncertain category, a standing rule a title cannot settle, or a missing release group tag. It asks rather than guessing.

Whose rules

A Rules dropdown picks DarkPeers, Zenith, or a tracker you add yourself. It changes the upload rules and the banned-group list, not the shared naming guide — so the same title can be clean on one and rejected on the other.

Add your own tracker

Paste a tracker's banned list straight off its page, tick the rules that apply, and it is checked like the built-in ones. Profiles export and import as JSON.

Audit a sweep

Audit loaded titles lists every release name on the page with its faults, as text you can copy — and keeps what you checked while browsing, so an audit can span a sweep of pages.

The release group, and where it is internal

New in 1.17.0.

The group tag at the end of a name is marked. Click it and you get every tracker the directory lists it as internal at — not just the first, since DON is HDBits and UHDBits, and LoRD is Bit-HDTV, HD-Torrents and UHDBits — a search for that group's other releases here, and the same search on the trackers you have chosen.

Listed as, not is

It ships with a community directory of internal groups, dated in the source. A directory can be stale, so every entry reads “listed as internal at”, and a group that is not on it is reported as not on it — never guessed at.

Your list, your corrections

Internal groups… takes a directory page pasted whole, or lines of Tracker|group group group. Save replaces the shipped list; Clear brings it back. It stays in your browser.

It shares the page politely

If another script has already made that tag a link, this one leaves it completely alone — no wrapping, no rewriting, nothing for two scripts to fight over.

Moderating a queue

On /torrents/pending, /torrents/rejected and /torrents/postponed.

A decision log

Every row gets Approved / Rejected / Asked the uploader / Left for someone else, ticked with the date so a sweep does not repeat itself. Rejecting or asking prompts for a note.

It records what you decided. It changes nothing on the tracker and never leaves your browser.

A reply, written from the findings

Inside the badge dialog: a draft message with the corrections numbered in the guide's own words, the release name and its link, and a closing line. Four outcomes, one suggested — a banned group suggests a rejection rather than a rename.

Manual checks appear as worth confirming, never as faults. Edit it before you copy it; nothing is sent.

What the page itself says

The TMDB title and year against the name; the Type and Resolution filed against what the name claims; the file list, containers, samples and whether a pack's files agree; whether MediaInfo or BDInfo was posted; and Dual-Audio / MULTi against the page's own original language.

Where a rule is in hand it is cited, and the finding is an error. Where none is, the finding says so — “the guide in hand states no container rule for this tracker, so check its upload rules.” Nothing invents a rule to sound authoritative.

Compare two releases

Paste a report on each side, or load the page's as A. It names what the two differ on and marks the larger number with the percentage. It does not pick a winner: source, encode quality and provenance are not in a report, and it says so.

The naming box

Check a title against the chosen tracker's rules before you upload, with reference fields (official title, original-language title, service) that make the manual checks decidable, and a searchable copy of the 261 streaming-service abbreviations.

Private notes

Per torrent, kept in your browser, never sent anywhere.

Is it already on a tracker you are on?

Links, built and opened only when you click them.

  • Already uploaded? — the exact release name searched on every tracker you have chosen, so you find out before you spend the effort. Exact means exact: a different edition or group will not match, and it says so.
  • On a request — every row on /requests gets a search button, and a request's own page shows the links under its title. 26 trackers are built in, each with its own editable search address; anything missing can be added.
  • Other versions — what else exists here, under the name on a torrent's own page, next to IMDb, TMDB, Trakt, Letterboxd, JustWatch, Blu-ray.com, srrDB, and MyAnimeList / MusicBrainz / Open Library / IGDB as the category warrants.
  • Search all opens them in tabs. Browsers allow one tab per click and silently block the rest, so if yours refuses a burst they are offered one at a time, with Copy every link as the fallback.

Only https addresses are accepted, a tracker that cannot carry the search is left out with the reason, and no login, cookie, passkey or API key is read or stored.

Installing it

  1. Install Tampermonkey if you do not have it.
  2. Click Install the script. Tampermonkey recognises a .user.js address and opens its own install page.
  3. Read what it asks for — the matches and the permissions are at the top — then press Install.
  4. Reload the tracker.

Updating later is the same click: Tampermonkey replaces the existing script rather than adding a second copy. Prefer to do it by hand? Open the file on GitHub, copy it, and paste it over the contents of a new Tampermonkey script.

If you download the file instead, do not double-click it — Windows will try to run it as a script rather than install it.

Reads, never writes

The whole point of the thing, and the part worth checking yourself.

No requests

Nothing is fetched, crawled, uploaded or downloaded. Every link opens only when you click it. There is no API access, no @connect beyond the original, and no cookie, passkey or credential is read.

No writing to the tracker

Nothing is posted, submitted, approved, rejected or edited on your behalf. It reads the page you are on and tells you what it found.

Local, bounded, yours

Notes, settings, the audit, the decision log, tracker profiles and the internal-groups list live in your own browser, each with a fixed cap, and are never sent anywhere.

A green ✓ means the supported title checks passed — not that the media, the source history or tracker approval were verified. Where the tool cannot know something it says so rather than guessing, and where it is applying a rule it names the rule.
