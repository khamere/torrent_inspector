# Code of conduct

## Expectations

Treat other participants with respect. Critique ideas and code rather than people. Welcome questions, explain disagreements constructively, and accept corrections.

Harassment, threats, discriminatory abuse, personal attacks, spam, and publishing someone else’s private information are not acceptable in project issues, pull requests, discussions, or other spaces maintained for this project.

## Reporting

Report concerns privately to **khamere@pm.me**. Include enough context to identify the incident. Do not post someone else’s private information in a public report.

## Enforcement

Maintainers may remove inappropriate content, ask participants to change their behavior, restrict participation, or block repeat or serious offenders. Actions should reflect the nature and severity of the conduct. Reports should be handled discreetly, with information shared only as needed to respond.

This is a project-specific draft, not an adopted external code-of-conduct template. Publishing it represents the maintainer’s decision to adopt and operate this policy.
